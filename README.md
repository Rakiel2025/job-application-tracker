<h1 align="left">
  <font face="Arial" color="#FFFFFF" size="6">Project Overview</font>
</h1>

<p align="left">
  <font face="Arial" size="4" color="#FFFFFF">
    The Job Application Tracker is a full-stack web
    application designed to help users manage and track
    their job applications.
</p>

<p align="left">
    <font face="Arial" size="4" color="#FFFFFF"> 
    Users can add, view, update and delete job
    applications, monitor application statuses and
    view statistics through a dashboard.
  </font>
</p>

<h1 align="left">
  <font face="Arial" color="#FFFFFF" size="6">Features</font>
</h1>

<ul>
    <li>User-friendly dashboard</li>
    <li>Add new job applications</li>
    <li>View application details</li>
    <li>Edit existing applications</li>
    <li>Delete job applications</li>
    <li>Search applications by company or job title</li>
    <li>Filter applications by status</li>
    <li>Dashboard application statistics</li>
</ul>
